# MDA Growth Systems credibility audit — Batch 13

Reviewed: 5 August 2026

## Verified public positioning

The current public site describes website development, lead-generation tools, CRM/workflow automation, paid advertising and related growth services. Batch 13 outreach mentions only the specific enquiry journey represented by each concept and does not repeat broad performance claims.

## Trust-chain issues requiring manual action

- **Brand naming:** the public site also uses “MDA / Modern Digital Agency”, which is not fully consistent with “MDA Growth Systems”.
- **Sending-domain mismatch:** connected Gmail sends as `michael@mdagrowthsystems.info`, while the public website is `mdagrowthsystems.com`.
- **Public contact email:** the public website displays `michaelaumann10@gmail.com`, creating another identity/domain mismatch.
- **Display name:** connected messages currently show “Michael”; the requested display name is “Michael | MDA Growth Systems”.
- **Branded demo domain:** no verified `demos.mdagrowthsystems.com` route is available, so public GitHub Pages links are used honestly.
- **SPF, DKIM and DMARC:** not verifiable with the connected tools in this execution. Confirm before scaled sending.

## Claims not used in outreach

The public site displays performance figures, ratings, lead volumes, guarantees, team/process claims and launch times. No independent evidence was available in this execution, so these claims were excluded from all twenty Batch 13 messages. Replace or support them with dated case studies, verifiable testimonials, measured outcomes and clear guarantee conditions.

## Recommended manual fixes

1. Standardise the legal/trading brand and wording across the website, Gmail display name and signature.
2. Configure and use a verified mailbox on `mdagrowthsystems.com` if available.
3. Replace the personal Gmail contact address on the public site with the verified matching-domain address.
4. Confirm SPF, DKIM and DMARC for the actual sending domain.
5. Add genuine case studies, before/after examples, named testimonials with permission and real team information.
6. Configure a branded demo domain before increasing cold-outreach volume.
