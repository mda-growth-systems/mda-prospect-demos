NETLIFY DEPLOYMENT
1. Drag only this folder into Netlify Drop or deploy it as the site publish directory.
2. Netlify will detect the data-netlify=true form in index.html.
3. Confirm Forms is enabled and run one test submission.
4. The form posts to thank-you.html on Netlify.
5. On GitHub Pages, script.js intentionally demonstrates the journey without sending or storing visitor data.
