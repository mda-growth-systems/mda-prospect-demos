MDA Growth Systems unofficial redesign concept for Independent Pest Control & Hygiene Services

Files
- index.html: public concept homepage
- thank-you.html: form completion page
- styles.css: responsive site styles
- script.js: mobile navigation and GitHub Pages demo-form behaviour
- hero-illustration.svg: original industry-specific concept artwork
- verification-notes.txt: research and fact controls
- outreach-email.txt: first-contact copy
- follow-up-email.txt: Re: follow-up copy

Deployment
1. Upload this individual folder to Netlify as a separate site.
2. Netlify detects the data-netlify form in index.html.
3. Enable form notifications in Netlify after deployment.
4. Test the public URL, navigation, phone/email links and thank-you page.

GitHub Pages behaviour
The script intercepts the form only on local/GitHub Pages demo hosts and opens thank-you.html without transmitting information. Netlify submissions are not intercepted.
