Laser Surveys Ltd — unofficial website concept

Files
- index.html: main concept page
- thank-you.html: safe prototype confirmation
- styles.css: responsive styling
- app.js: mobile navigation and browser-only brief preview
- creative-directions.txt: three directions and selection rationale
- verification-notes.txt: source and factual constraints
- qa-checklist.txt: QA record
- outreach-email.txt / follow-up-email.txt: approval copy

Deployment
This folder is static and can be deployed individually to Netlify or GitHub Pages. The main index.html is in the folder root.

Form behaviour
The form is a clearly labelled interactive prototype. JavaScript validates the fields, builds a browser-only summary and redirects to thank-you.html. No data is transmitted or stored.
