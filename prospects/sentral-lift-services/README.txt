README — Sentral Lift Services website concept

Folder: prospects/sentral-lift-services/
Main file: index.html
Confirmation file: thank-you.html

Deployment
This is a static website. Deploy the individual folder as the publish root on Netlify, or serve it through GitHub Pages from the repository root.

Form behaviour
The enquiry interface is an interactive prototype. It builds a live summary in the browser and navigates to thank-you.html. It does not send or store information and does not pretend to be connected to a live CRM.
